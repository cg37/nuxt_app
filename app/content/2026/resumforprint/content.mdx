## 个人项目

### PlayWrightPdfService(端到端 PDF 生成基础设施)

从零搭建了一套包含后端服务、前端 SDK、安全认证、容器化部署的 PDF 生成技术方案。
后端使用 .NET 10 + Playwright 渲染引擎, 前端侧开发了 Nuxt 3 Module 与 Vue Composable,
生产部署上, 服务运行在 Docker 容器中, 通过 Cloudflare Zero Trust (Access + Tunnel) 实现零暴露面的公网访问,
同时内置 API Key 第二层认证兜底。服务已考虑国内网络环境, Dockerfile 使用阿里云镜像加速。

- [NPM仓库地址](https://www.npmjs.com/package/contribution-chart) [GitHub项目地址](https://github.com/cg37/contribution-chart)

### Mac信息验证码复制 (OTPilot)

一个轻量级 macOS 菜单栏应用, 使用 Swift 原生开发, 通过只读方式监控 chat.db 短信数据库, 提取中英文验证码, 复制到剪贴板并提醒用户。自动过滤手机号、订单号等干扰项, 保留最近 50 条历史记录, 已上架供个人使用, 适用于依赖短信验证码登录的开发者与高频用户。

- [项目地址](https://github.com/cg37/OTPilot)

### Vision Bump

### natural2bash (自然语言转 Bash 命令)

一个基于 AI 的命令行工具, 将中文/英文自然语言描述自动转换为可执行的 `Bash` 命令
技术栈使用 `Node.js` 构建 `CLI` 框架, `Chalk` + `Ora` 优化终端视觉效果。内置 `GitHub Actions` 自动发布流水线:推送代码触发多版本 `Node.js(18.x / 20.x / 22.x)`矩阵测试的 `CI` 流水线, 发布 `GitHub Release` 后自动触发 `npm` 公共仓库发布的 `CD` 流水线。

- [项目地址](https://github.com/cg37/natural2bash)

### BestDNS

一个基于 `Tauri v2` 开发的跨平台 DNS 测速桌面工具。前端使用 `React` + `TypeScript` + `Mantine UI`, 后端采用 `Rust`实现 `DNS` 解析。支持一键测试 12 个国内外主流 DNS 服务器延迟, 帮助用户快速选择最佳 `DNS`。支持 `Windows` 和 `macOS` 双平台, 通过 `GitHub Actions` 实现自动构建与发布。

- [项目地址](https://github.com/cg37/BestDNS)

### FluxChat

FluxChat — 基于 Vue 3 的 ChatGPT 客户端。核心基于 SSE 协议实现流式输出,
通过 @microsoft/fetch-event-source 逐 token 解析 OpenAI 数据流, 实时增量渲染至 UI,
达到打字机般逐字呈现效果。同时实现了自动滚动与用户交互暂停的智能联动:AI 输出期间话题区自动跟随滚动;
用户触摸或滚轮操作后, 自动滚动暂停, 避免打断阅读, 交互恢复后重新跟随, 整体提升了长文本对话的阅读连贯性和操作可控性。

- [项目地址](https://github.com/cg37/FluxChat#)
